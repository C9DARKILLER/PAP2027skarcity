# PAP2027skarcity
skarcity é um videojogo de tiro tático em perspetiva competitiva (PvP) no formato 2v2. Inspirado na ambientação e nas mecânicas de sobrevivência de The Last of Us, o jogo coloca quatro jogadores divididos em duas equipas numa arena fechada e simétrica. O objetivo é exclusivamente a eliminação completa da equipa adversária.
